# Portfolio 4 – NoSQL and Advanced Data Models

Case study: Clinix Diagnostics Hospital Management System (academic simulation).

- Database: `clinix_nosql`
- DBMS: MongoDB
- Collection: `patients`
- Model: patient documents with embedded appointment subdocuments
- Implementation script: `sql/clinix_nosql_mongodb.js`
- Report: `Portfolio_4_NoSQL_and_Advanced_Data_Models.md`
- Evidence: `evidence/Screenshots/`

Run the script in `mongosh` against a local MongoDB server. The script creates the collection and inserts the sample documents, so do not rerun the insertion section against the same populated database unless you first clear the collection or use a fresh database.
