\# Clinix Diagnostics Hospital Management System (CDHMS)



\## MIVA Advanced Database Systems Portfolio



\### Project Overview



This project focuses on the design, implementation, and optimisation of a relational database for a simulated hospital management system using Clinix Diagnostics Hospital as the case study.



The system is designed to demonstrate advanced database concepts through practical implementation.



\### Project Objectives



\- Design and implement a relational database.

\- Apply database normalization principles.

\- Implement primary keys, foreign keys, and constraints.

\- Perform SQL queries and joins.

\- Analyse query execution and optimisation.

\- Demonstrate transaction management and concurrency.

\- Explore NoSQL database models.

\- Examine distributed and cloud database architectures.

\### Data Privacy



All patient and hospital records used in this academic project are fictional.



This is an academic simulation and is not an officially commissioned Clinix Diagnostics Hospital system.
